# Abhedya-Chakra · online demo

Money-mule detection, tracing and freeze engine for the Indore Police Cyber Crime Cell (Void Hacks 8.0, Team
Srijan-Coders). This demo runs on a 50,000-row sample of the official file, which contains all 300 victims and
1,073 mule accounts. Uploading and changing cases is switched off here; the workstation itself runs offline on
one laptop.

Source, documentation and results: https://github.com/VoidHacks-8-O/Srijan-Coders
